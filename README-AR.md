# iraq study .ai — ملفات جاهزة للرفع إلى GitHub

هذه نسخة أولية لموقع مساعد دراسي عربي، مصممة للموبايل، وتستخدم GigaChat API من خلال خادم Node.js حتى لا ينكشف المفتاح للزوار.

## ما الذي يعمل؟
- اختيار الصف والمادة.
- إدخال الصفحة ورقم السؤال (اختياري).
- اختيار حل نموذجي أو تلخيص.
- كتابة نص السؤال أو الموضوع وإرسال الطلب إلى GigaChat.
- عرض الإجابة ونسخها.

## مهم جداً
- **رقم الصفحة ورقم السؤال وحدهما لا يضمنان أن النموذج يعرف محتوى كتابك.** اكتب نص السؤال كاملاً. هذه النسخة لا تحتوي على الكتب الوزارية العراقية داخلها.
- الذكاء الاصطناعي قد يخطئ؛ راجع الإجابات مع الكتاب الرسمي.
- GitHub Pages لا يشغّل هذا المشروع وحده؛ لأن الموقع يحتاج خادماً لتخزين مفتاح API وإرسال الطلبات.
- خطة الاستضافة المجانية قد تنام بعد عدم الاستخدام، كما أن حدود GigaChat وتوفره تعتمد على حسابك وشروط الخدمة.
- لم تتم إضافة تسجيل حسابات أو Premium في هذه النسخة؛ هذه نسخة أولى تركز على حل الأسئلة.

## النشر من الآيفون
1. نزّل ملف ZIP وفك ضغطه باستخدام تطبيق الملفات.
2. افتح https://github.com/new في Safari وأنشئ مستودعاً جديداً (Repository)، مثلاً `iraq-study-ai`. يمكنك جعله Public.
3. ارفع الملفات والمجلد `public` إلى جذر المستودع. تأكد أن `package.json` و`server.js` و`render.yaml` في الجذر.
4. افتح https://render.com وأنشئ حساباً، ثم اختر إنشاء Web Service واربط مستودع GitHub. إذا عرض Render خيار استخدام Blueprint، يمكنك اختيار ملف `render.yaml`.
5. من إعدادات الخدمة، أضف متغير البيئة `GIGACHAT_CREDENTIALS` وضع بيانات المصادقة التي حصلت عليها من حساب GigaChat الرسمي. لا تكتبها في ملفات GitHub ولا ترسلها في المحادثة.
6. تأكد من أن `GIGACHAT_SCOPE` يطابق نوع الوصول الذي فعّلته في حسابك. قد تحتاج لتعديل `GIGACHAT_MODEL` إلى اسم نموذج متاح في حسابك.
7. انتظر انتهاء النشر وافتح رابط الموقع الذي تعطيك إياه الاستضافة.

## إذا ظهر خطأ
- خطأ في المصادقة: تحقق من بيانات GigaChat وصلاحية الوصول.
- خطأ في النموذج: راجع اسم النموذج المتاح لحسابك وعدّل `GIGACHAT_MODEL`.
- الموقع يفتح لكن ما يجاوب: افتح سجلات الخدمة في Render؛ قد تكون الخدمة نائمة أو بيانات API غير صحيحة.

هذه الملفات نقطة بداية وليست ضماناً أن كل حساب GigaChat أو كل إعداد استضافة سيعمل دون تعديل. لا تضع أسرار API داخل الواجهة الأمامية أو في مستودع عام.
