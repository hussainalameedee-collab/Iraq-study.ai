# iraq study .ai — نسخة التصميم والحسابات

## الملفات
ارفع ملفات هذا المشروع إلى جذر مستودع GitHub، بحيث يكون `index.html` و`style.css` و`app.js` و`server.js` و`package.json` في المستوى الرئيسي نفسه.

## مهم جداً
- GitHub Pages يشغّل الواجهة الثابتة فقط، ولا يشغّل `server.js` أو تسجيل الحسابات أو لوحة الـ Owner أو الذكاء الاصطناعي.
- لتشغيل الحسابات ولوحة الـ Owner والحل بالذكاء الاصطناعي، انشر المشروع كخدمة Node.js. يمكن استخدام Render، لكن الخدمة المجانية قد تتوقف مؤقتاً عند عدم الاستخدام.
- لا تضع كلمات المرور أو مفاتيح API في ملفات GitHub العامة.

## إعداد الخادم
في إعدادات Environment لدى خدمة الاستضافة، أضف:
- `OWNER_USERNAME` = `حسين العميدي`
- `OWNER_PASSWORD` = كلمة المرور التي اخترتها (لا تكتبها في GitHub؛ كلمة المرور القصيرة سهلة التخمين، والأفضل اختيار كلمة أقوى)
- `SESSION_SECRET` = سلسلة عشوائية طويلة وسرية
- `GIGACHAT_CREDENTIALS` = بيانات اعتماد GigaChat الخاصة بك
- `GIGACHAT_SCOPE` = `GIGACHAT_API_PERS`
- `GIGACHAT_MODEL` = اسم النموذج المتاح لحسابك، وتحقق منه من لوحة GigaChat

ثم اجعل أمر البناء `npm install` وأمر التشغيل `npm start`.

## التخزين
هذا الإصدار يحفظ الحسابات وسجل النشاط في ملف `data.json`. إذا كانت الاستضافة تمسح الملفات عند إعادة النشر أو إعادة التشغيل، فقد تحتاج إلى قرص دائم أو قاعدة بيانات خارجية حتى لا تضيع الحسابات. تخزين جلسات تسجيل الدخول الحالي داخل ذاكرة الخادم، وقد يطلب الموقع تسجيل الدخول مجدداً بعد إعادة تشغيل الخدمة.

## الميزات الموجودة
- واجهة عربية RTL متجاوبة، سوداء مع ذهبي وأزرق.
- زر Get Premium والرسالة: «يرجى التواصل مع +79997006869 للحصول على البريميوم بشكل مجاني».
- تسجيل وإنشاء حسابات باسم مستخدم وكلمة مرور (الحد الأدنى 8 أحرف لكلمة مرور المستخدم).
- حساب Owner من متغيرات الخادم، يعرض الحسابات وسجل النشاط ويمنح/يسحب Premium بمدة محددة أو دائم.
- حل أو تلخيص عبر GigaChat عند إضافة بيانات الاعتماد الصحيحة.

## تنبيه
هذه نسخة أولية للتشغيل وليست تدقيقاً أمنياً كاملاً. اختبرها قبل مشاركة الرابط العام، واستخدم كلمة مرور Owner قوية. لا تضمن خدمة الذكاء الاصطناعي صحة 100%، ولا يحتوي هذا الإصدار على استخراج نص من صور الأسئلة بعد.
